# Checkpoints and Assessments

This folder contains quizzes and coding tasks to test your understanding of Python basics and OOP concepts covered in the orientation phase.

## Contents

1. **quiz.md** - 10 questions (MCQ + code output) testing Python fundamentals
2. **coding_task.py** - Library class implementation task
3. **coding_task_solution.py** - Solution with explanations

## How to Use

1. First, complete the quiz in `quiz.md`
2. Then, attempt the coding task in `coding_task.py`
3. Check your answers against the solution

Good luck!
